# Decisoes Tecnicas

- Stack adotada: Next.js App Router, TypeScript, Tailwind CSS, Motion, Zod e Vercel Analytics.
- Server Components por padrao; Client Components apenas para menu mobile, animacoes e formulario interativo.
- Formulario B2B usa Server Action com validacao Zod.
- Paleta inicial derivada do catalogo/logo:
  - `#F3EF00` amarelo Candy
  - `#24469B` azul institucional
  - `#40A0DE` azul claro
  - `#202B60` azul escuro
  - `#EF233C` CTA principal
  - `#E52F77`, `#5BBD87`, `#5E3D7C`, `#FF8A00` apoio e categorias
- PDF renderizado virou asset inicial em `public/catalog/`.
- Landings SEO foram implementadas como rotas reais para intencoes estrategicas.
