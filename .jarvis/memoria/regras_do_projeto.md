# Regras do Projeto

- B2B antes de B2C.
- Todo caminho estrategico deve levar a WhatsApp, catálogo ou cotação.
- Não inventar claims comerciais, legais ou institucionais.
- Dados pendentes devem aparecer como `[PENDENTE DE CONFIRMAÇÃO]`.
- Usar imagens do catálogo fornecido ou assets oficiais aprovados.
- Manter mobile-first e sticky CTA sem cobrir conteudo.
- Validar formulário no servidor.
- Documentar riscos antes de considerar pronto.
