# Regras do Projeto

- B2B antes de B2C.
- Todo caminho estrategico deve levar a WhatsApp, catalogo ou cotacao.
- Nao inventar claims comerciais, legais ou institucionais.
- Dados pendentes devem aparecer como `[PENDENTE DE CONFIRMACAO]`.
- Usar imagens do catalogo fornecido ou assets oficiais aprovados.
- Manter mobile-first e sticky CTA sem cobrir conteudo.
- Validar formulario no servidor.
- Documentar riscos antes de considerar pronto.
